Aturan parsing manifest

File berupa teks UTF-8 dengan ukuran maksimum 48 MiB. Field string harus berupa assignment tingkat atas dengan tanda kutip tunggal atau ganda. id diubah menjadi huruf kecil, karakter tidak valid diganti underscore, dan hasilnya dibatasi hingga 64 karakter. Field yang tidak ada menggunakan nama file, versi 1.0, dan ikon extension sebagai default.

Plugin library dimulai sebelum konsumennya. __dependencies__ mendeklarasikan id plugin yang diperlukan, menentukan urutan startup, dan mencegah konsumen berjalan ketika dependensi tidak ada atau dinonaktifkan. Class dan object Java dapat diekspor dengan nama lalu diimpor oleh plugin dependen.

Nilai switch dan slider menggunakan penyimpanan JSON per plugin yang sama dengan get_setting/set_setting. Host menyimpan nilai sebelum memanggil on_setting_changed({key, value}); slider memancarkan event setelah interaksi selesai.

Asal kunci pengaturan

Tidak ada katalog kunci yang telah ditentukan. Pengembang plugin membuat kunci string apa pun dan menggunakan ejaan yang sama saat membaca, menulis, atau mendeklarasikan item Settings. Kunci hanya dapat bertabrakan dalam plugin yang sama karena setiap pluginId memiliki penyimpanan terpisah. Gunakan nama stabil seperti capture_enabled atau radio.power; mengubah kunci akan membuat pengaturan baru.

__id__ = "ir_storm_hook"
__name__ = "IR Storm Hook"
__version__ = "1.0.0"
__icon__ = "rounded:settings_input_antenna"

from java import jarray, jint

class IrStormHook(BasePlugin):
    def __init__(self):
        super().__init__()
        self.current_route = ""

    def on_plugin_load(self):
        self.hook_action("infrared.transmit", 100)

    def on_navigation(self, route):
        self.current_route = str(route)

    def hook_infrared_transmit(self, payload):
        if self.current_route not in ("ir_storm", "other/ir_storm"):
            return None

        frequency = int(payload["frequency"])
        pattern = [int(value) for value in payload["pattern"]]
        ok = self.send_to_external_ir(frequency, pattern)
        return {
            "handled": True,
            "result": ok
        }

    def send_to_external_ir(self, frequency, pattern):
        android = self.api.getAndroid()
        java_pattern = jarray(jint)(pattern)
        return android.irTransmit(frequency, java_pattern)

Pemuatan DEX dan plugin library

Pertahankan plugin sebagai satu file Python yang mudah dibaca sambil menyematkan kode Java atau Kotlin terkompilasi dan berbagi kapabilitas native dengan plugin lain.

DEX adalah kode native tepercaya

DEX yang dimuat berjalan di dalam proses Dolphy dengan izin aplikasi. Selalu publikasikan SHA-256, verifikasi sebelum pemuatan, dan jangan pernah menjalankan payload hasil download yang tidak tepercaya.

Sematkan dan muat DEX mentah

Simpan DEX mentah sebagai Base64 dalam file .dolphyplugin. Dolphy menghapus whitespace, mendekode, memverifikasi SHA-256, dan membuat class loader. DEX mentah menggunakan InMemoryDexClassLoader pada Android 8+; Android lebih lama serta payload JAR/APK berbasis ZIP menggunakan file code-cache privat read-only dan DexClassLoader.

Batas dan siklus hidup

Ukuran .dolphyplugin dapat mencapai 48 MiB; setiap payload DEX/JAR/APK hasil decode dapat mencapai 32 MiB. Android tidak dapat me-unload Class setelah direferensikan kode. Dolphy melepas loader dan export ketika pemilik berhenti, tetapi restart proses adalah satu-satunya cara yang menjamin unload lengkap setelah pembaruan. Buat nama export unik secara global dan tutup thread, receiver, socket, serta handle perangkat keras dalam on_plugin_unload.

Instal, perbarui, dan pulihkan

Dolphy menangani file .dolphyplugin dan menampilkan sheet Material ringkas yang terbuka sebagian sebelum kode apa pun dijalankan. Setelah instalasi, sheet ditutup dan keberhasilan dikonfirmasi melalui toast Dolphy.

  1. 1
    Buka file

    Ketuk file .dolphyplugin di file manager, lalu pilih Dolphy.

  2. 2
    Periksa metadata

    Periksa ikon, penulis, versi, deskripsi, serta kapabilitas yang terdeteksi atau dideklarasikan, seperti pemuatan DEX, download, file, hook, Bluetooth, Wi-Fi, USB, IR, Root, Shizuku, dan Shell.

  3. 3
    Instal

    Kode hanya berjalan setelah Anda menekan Instal. Membuka kembali file akan memperbarui plugin.

previewMembaca metadata dan ukuran tanpa menjalankan Python; menunjukkan apakah id yang sama sudah terinstal.
install / updateMenyimpan source secara privat dan langsung menjalankannya kecuali Mode Aman aktif. Menginstal id yang sama menggantikan sesi sebelumnya dan mempertahankan status sematan.
enable / disableMemulai atau menghentikan runtime dan menghapus semua modul, pengaturan, layar, service, dan action terdaftar saat dinonaktifkan.
pin / sharePin mengubah urutan. Share mengekspor source asli sebagai application/x-dolphy-plugin dengan ekstensi .dolphyplugin.
deleteMenghentikan runtime dan menghapus source, metadata, registrasi, serta penyimpanan pengaturan privat plugin secara permanen.
startup failurePlugin yang tidak dapat dimulai disimpan dalam keadaan nonaktif saat instalasi; source tersimpan yang rusak dapat dikarantina sebagai .broken saat pemulihan.
health_and_safety
Mode Aman otomatis

Jika aplikasi tertutup saat kode plugin berjalan, peluncuran berikutnya akan menonaktifkan semua plugin dan menawarkan log crash. Setelah itu, Anda dapat mengaktifkan plugin satu per satu.

Perilaku Mode Aman

Sheet pemulihan menjelaskan bahwa error plugin telah menutup aplikasi dan menawarkan Salin log atau Nonaktifkan Mode Aman. Menutup sheet membiarkan Mode Aman aktif dan item persisten tetap tampil di layar Plugin. Selama aktif, semua plugin dinonaktifkan dan tidak dapat diaktifkan hingga Mode Aman dimatikan.
